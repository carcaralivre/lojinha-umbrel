# Lojinha do Umbrel

Loja comunitária de apps para UmbrelOS.

## Como adicionar no seu Umbrel

1. Abra a **App Store** no seu Umbrel.
2. Clique nos **três pontinhos (⋯)** no canto superior direito.
3. Escolha **Community App Stores**.
4. Cole esta URL e clique em **Add**:

```
https://github.com/carcaralivre/lojinha-umbrel
```
